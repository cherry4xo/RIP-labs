HTTPS в локальном фронтенде

# 1. Создать самоподписанный сертификат

# 2. Изменить vite.config.ts:
# server: {

#     key: fs.readFileSync('key.pem'),
#     cert: fs.readFileSync('cert.pem')
#   },
#   proxy: {...}
# }

🚨 РЕШЕНИЕ ПРОБЛЕМ

Backend не доступен

Симптомы: Ошибки в консоли, mock данные загружаются
Решение:
# Проверить запущен ли backend
curl http://localhost:8080/api/vulnerabilities

# Если нет - запустить backend
cd /Users/n.m.kulakov/projects/RIP-labs/backend
uvicorn main:app --reload --host 0.0.0.0 --port 8080

CORS ошибки

Симптомы: Access-Control-Allow-Origin ошибка в консоли
Решение: Прокси уже настроен в vite.config.ts:76-82

Redux DevTools не работает

Решение:
# Установить расширение Redux DevTools в браузере
# Chrome: https://chrome.google.com/webstore/detail/redux-devtools/
# Firefox: https://addons.mozilla.org/firefox/addon/reduxdevtools/

PWA не устанавливается

Решение:
- Проверить что открыта production сборка (npm run build && npm run preview)
- Или открыт HTTPS (в production или localhost с сертификатом)
- Проверить manifest в DevTools → Application

Tauri не собирается

Решение:
# Установить Rust (если еще не установлен)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# Установить системные зависимости (macOS)
xcode-select --install

Изображения не загружаются

Решение:
- Проверить что MinIO запущен и доступен
- Проверить image_url в базе данных
- Placeholder должен работать: /images/services/placeholder.png
